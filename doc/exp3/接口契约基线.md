## 二、统一响应契约

```json
{"errno": 0, "errmsg": "成功", "data": {...}}
```

- HTTP 状态恒为 200；`errno` 承载业务语义。
- 通用码：401 参数错误、402 参数值错误、501 未登录、502 系统内部错误（**未捕获异常兜底，等价于 500**）、503 不支持、504 数据过期、505 数据更新失败、506 未授权。
- 业务码：708 / 710 / 711 / 720 / 721 / 724 / 725 / 740~742 / 750~752。
